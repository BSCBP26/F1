# F1 Engineering Lab

Lab interaktif F1 2026 dalam satu file HTML (tanpa dependency, tinggal buka `index.html` di browser).

- **Tunnel 3D**: mobil F1 2026 3D (WebGL) dengan garis aliran udara dan peta tekanan ala CFD, active aero Corner/Straight Mode, dan rear wing Standar / Red Bull Macarena / Ferrari Macarena.
- **Track 3D**: replay lap di sirkuit 3D dengan HUD (kecepatan, gigi, baterai, mode aero, keausan ban) dan 4 kamera.
- **Tunnel 2D**: CFD Lattice-Boltzmann (D2Q9) real-time di potongan tengah mobil.
- **Setup aero**: model downforce/drag per komponen, balance, top speed.
- **Power unit**: split ICE/MGU-K 2026, taper di atas 290 km/j, Overtake Mode.
- **Lap sim**: simulasi point-mass dengan manajemen energi baterai, stint dan tyre degradation (Soft/Medium/Hard).

Aliran 3D dan angka aero/ban adalah model perkiraan untuk belajar, bukan data tim.
